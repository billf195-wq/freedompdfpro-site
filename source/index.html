Source code for open-source parts

Freedom PDF Pro includes a few open-source parts under GNU licenses. They are shipped unmodified. Below is the complete source code for the exact versions included, from their official sources. Their license texts are in the licenses folder of the program and under About > Licenses in the app.

PartVersionLicenseWhere in Freedom PDF ProSource code

(tag 3.6.1rel; includes the MuPDF copy it is built with)

GEOS3.14.1GNU LGPL-2.1python\Lib\site-packages\shapely.libs\geos*.dll, geos_c*.dll (from shapely 2.2.0) geos-3.14.1.tar.bz2
shapely 2.2.0 (BSD, builds the DLLs): shapely-2.2.0.tar.gz
GNU libiconv1.17GNU LGPL-2.1linked into python\Lib\site-packages\lxml\etree*.pyd (lxml 6.1.3 Windows build) libiconv-1.17.tar.gz
lxml 6.1.3 (BSD, links it): lxml-6.1.3.tar.gz

Replacing these parts

You may replace GEOS (swap the DLLs in shapely.libs) and lxml with libiconv (rebuild lxml 6.1.3 from source with your own libiconv and put the new .pyd files in place) with your own changed or newer builds. SumatraPDF is a separate program and may be used, changed and shared under the GPL. The Freedom PDF Pro license does not forbid this, or reverse engineering to debug such changes.
